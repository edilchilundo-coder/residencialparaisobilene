Tema WordPress de luxo para o Residencial Paraíso Bilene — apartamentos T1 e T2
na Praia do Bilene, Moçambique.

== Descrição ==

Design elegante em tons âmbar e escuros, tipografia Playfair Display + Inter,
totalmente responsivo com menu hambúrguer mobile, secções para Apartamentos
(T1/T2/Quartos), Galeria, Restaurante, Lazer, Blog e Contactos.

Inclui:

* Página inicial (front-page.php) com hero, barra de pesquisa de reservas,
  features, apartamentos, galeria, testemunhos e destaques do blog.
* Custom Post Type "Apartamento" com taxonomia "Tipo".
* Customizer para telefone, WhatsApp, email, endereço, título/subtítulo do hero.
* Botão flutuante de WhatsApp integrado em todas as páginas.
* Áreas de widgets para sidebar e rodapé.
* Importador de conteúdo demo com 1 clique (Aparência → Importar Demo).
* Páginas pré-criadas: Início, Apartamentos, Restaurante, Lazer, Galeria,
  Blog, Contactos, Sobre Nós.
* Imagens demo (piscina, apartamentos, fachada, restaurante, praia do Bilene).

== Instalação ==

1. Compacte a pasta `residencial-paraiso-bilene/` num ficheiro ZIP
   (ou descarregue o ZIP já gerado pelo Lovable).
2. No painel WordPress, vá a Aparência → Temas → Adicionar novo → Carregar tema.
3. Carregue o ZIP, instale e ative.
4. Vá a Aparência → Importar Demo e clique em "Importar Conteúdo Demo".
5. Vá a Aparência → Personalizar → Contactos & Reservas para configurar
   telefone, WhatsApp, email, endereço e textos do hero.
6. Vá a Aparência → Menus e atribua o menu "Principal" à localização
   "Menu Principal" (já é feito automaticamente pelo importador).
7. Vá a Definições → Leitura: "Página inicial" = Início, "Página de
   publicações" = Blog (já é feito automaticamente pelo importador).
